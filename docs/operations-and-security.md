# 运维与安全

只接受包配置指定的 GitHub 仓库和精确资产。latest 选择上游发布列表中首个非草稿版本。构建校验上游摘要、大小、APK 数据、包名、版本和架构；签名前独立查询上游，核对标签提交、资产 ID 和摘要，来源变化即停止。

软件包保留上游内容、依赖和许可证，仅追加仓库签名。设备上的 APK 负责依赖解析。清单记录原始和签名后摘要、Release、源码提交及工具链版本。

生产私钥仅放在 `repository-signing` Environment Secret `APK_SIGNING_KEY`。环境限制默认分支并要求审批。临时密钥文件权限为 0600，步骤结束删除，不上传、不写日志。PR 和安装检查不使用生产私钥。

每次重新签名当前包和索引，生成全站 `SHA256SUMS` 与 RSA/SHA-256 签名，验证通过后整体部署。旧 APK、源码和清单不合并，发布失败不触碰线上站点。不提供历史下载或回滚源；设备先更新索引再安装。

首次信任公钥前，与维护者提供的可信指纹或可信 Actions 签名任务摘要核对。轮换密钥前先分发新公钥，再更换 Secret 并重新发布。

设备直接安装公钥、添加 latest 地址，订阅和移除步骤见 [README](../README.md)。保留官方 feeds 解析固件和内核模块依赖。

| 问题 | 处理 |
|---|---|
| GitHub 限流或下载失败 | 重试工作流，不发布空源 |
| 资产缺失或无 digest | 确认上游发布完整 |
| 包名、版本或架构不符 | 检查资产模式和上游包 |
| kmod 依赖不满足 | 确认官方 feeds 与固件内核匹配 |
| 签名、验证或安装检查失败 | 修复后重新发布 |
| Pages 部署失败 | 检查 Actions 发布源、环境限制及权限 |
